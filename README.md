# ASCHIP Hidráulica

Ferramentas de hidráulica da ASCHIP para o **Autodesk Revit 2024**: redes de água fria, água
quente e esgoto, dimensionamento, memorial de cálculo, detalhamento e lista de materiais.

Este repositório só distribui o instalador. Não contém o código do programa.

## Descarregar

Descarregue o `ASCHIP_Hidraulica_Setup_<versão>.exe` da
[última versão](https://github.com/ASCHIP1/aschip-hidraulica/releases/latest) e corra-o.

- Windows, com o Revit 2024 instalado.
- Instala só para o utilizador actual, sem pedir administrador.
- Feche o Revit antes de instalar.

No Revit aparece o separador **ASCHIP HIDRAULICA**. Ao usar um botão pela primeira vez, o
programa mostra o código deste computador, para pedir a sua chave de licença à ASCHIP.

## Actualizar

O programa procura versões novas sozinho, ao abrir o Revit (no máximo uma vez por dia). Também
pode carregar em **Actualizar**, no painel ASCHIP. A actualização instala-se quando fecha o Revit;
a licença e as definições mantêm-se.

## Remover

Em **Definições > Aplicações**, escolha **ASCHIP Hidráulica** e **Desinstalar**.
